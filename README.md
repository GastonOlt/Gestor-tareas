# 🗂️ Gestor de Tareas

Aplicación web desarrollada en **Node.js** y **Express** que permite gestionar tareas de forma sencilla y eficiente.  
Incluye autenticación mediante **JWT**, manejo de usuarios, y persistencia de datos con **PostgreSQL**.

---

## 📋 Descripción General

El **Gestor de Tareas** permite a los usuarios:
- Registrarse e iniciar sesión.
- Crear, editar y eliminar tareas personales.
- Organizar tareas por categorías.
- Mantener la sesión activa mediante **tokens JWT**.
- Mostrar alertas interactivas en el frontend con **SweetAlert2**.

El objetivo del proyecto es brindar una base sólida para sistemas de productividad o gestión de pendientes, aplicando buenas prácticas de desarrollo backend y manejo de seguridad.

---

## ⚙️ Tecnologías Utilizadas

- **Node.js** → Entorno de ejecución del servidor.  
- **Express.js** → Framework web para construir el backend.  
- **PostgreSQL** → Base de datos relacional.  
- **bcrypt** → Encriptación de contraseñas.  
- **jsonwebtoken (JWT)** → Autenticación basada en tokens.  
- **cookie-parser** → Lectura y gestión de cookies.  
- **SweetAlert2** → Alertas visuales en la interfaz.
